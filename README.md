## Интеграция Sputnik (Наш Дом / Спутник) для Home Assistant

Custom-интеграция для видеопотока с домофона и открытия двери через приложение
«Наш Дом» .

### Возможности

- **`camera`** — видеопоток с домофона (отдача через штатную интеграцию
  `stream` Home Assistant).
- **`switch`** — моментальная кнопка «открыть дверь» по каждому устройству.

### Установка

1. Установите HACS (Home Assistant Community Store).
2. В HACS добавьте репозиторий этой интеграции.
3. Найдите интеграцию «Nash dom (Sputnik)» и установите её.
4. Перезапустите Home Assistant.

### Настройка

1. В HA: **Настройки → Устройства и сервисы → Добавить интеграцию → Sputnik**.
2. Введите телефон, зарегистрированный в приложении «Наш Дом / Спутник».
3. Введите SMS-код, полученный в ответ.
4. Готово: появятся камера(ы) и кнопка открытия двери.

### Требования

- Home Assistant 2023.6.0 и выше.
- `stream` интеграция включена (в `configuration.yaml`):
  ```yaml
  stream:
  ```

### Конфиденциальность

Интеграция использует ваш аккаунт «Наш Дом / Спутник» по тем же правам, что
и мобильное приложение: просмотр видеопотка и открытие двери.
